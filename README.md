# Rectal-cancer-tumour-regression-modelling.
MSc thesis work at IIT Hyderabad and BIACH on phenotype-based mathematical modeling of tumour regression dynamics during chemoradiotherapy in rectal cancer.

#### About This Project

This repository contains the computational work associated with my MSc Medical Physics thesis, carried out at the Indian Institute of Technology Hyderabad (IIT Hyderabad) and Basavatarakam Indo American Cancer Institute (BIACH).

The project focuses on mathematical modeling of patient-specific tumour regression dynamics during long-course chemoradiotherapy in rectal cancer, with the aim of characterizing temporal regression phenotypes and identifying potential window for adaptive radiotherapy replanning.
## Research Objective

The primary objective of this work is to investigate whether patient-specific tumour regression follows distinct temporal patterns during chemoradiotherapy.

The study aims to:
- Characterize tumour regression kinetics across the course of treatment.
- Identify distinct regression phenotypes based on temporal changes in regression rates.
- Compare phase-wise and single-exponential models using quantitative model evaluation metrics.
- Explore whether regression kinetics can help identify potential adaptive replanning window.

 ## Methodology

- Tumour volume data were obtained from serial treatment imaging.
- Tumour volumes were normalized to the baseline volume.
- Temporal regression kinetics were modeled using phase-wise exponential models.
- Regression phenotypes were characterized using phase-specific regression rates.
- Model performance was evaluated using R², RMSE, AIC, and BIC.
- Potential adaptive replanning windows were explored from the modeled regression trajectories.

 ## Key Results

- Phase-wise exponential modelling was preferred over the single-exponential model across the analysed patient cohort based on AIC and BIC.
- Distinct temporal tumour regression phenotypes were observed between patients.
- Regression kinetics were used to explore potential adaptive replanning window.
